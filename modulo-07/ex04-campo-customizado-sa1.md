# Exercício 4 — Campo customizado na SA1

## Campo criado

Nome do campo:


A1_XAPELID


Descrição:


Apelido Cliente


Configuração:

| Propriedade | Valor |
|---|---|
| Tipo | Caracter |
| Tamanho | 30 |
| Título | Apelido |

---

## Passos realizados

1. Acessar o SIGACFG.

2. Abrir o cadastro de campos (SX3).

3. Localizar a tabela SA1.

4. Criar o campo seguindo o padrão dos campos customizados.

5. Salvar as alterações.

6. Atualizar o dicionário.

7. Abrir novamente o SmartClient.

8. Conferir que o campo aparece na tela de cadastro de clientes.
